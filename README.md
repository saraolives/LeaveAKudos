This extension is for adding a poll to the end of a Dreamwidth entry. The poll will have only one option, which is to leave a Kudos. Thanks to yourlibrarian on Dreamwidth for providing the poll code and the idea!

To install in Firefox:
- Download the ZIP and unpack it anywhere on your computer
- Open Firefox and go to `about:debugging`
- Open "This Firefox" in the left-hand menu
- Click "Load Temporary Add-On"
- Open the `leaveakudos.js` file

To install in Chrome:
- Go to `chrome://extensions` in a new tab. Or, click the Chrome menu, hover over More Tools, then select Extensions.
- Enable Developer Mode by clicking the toggle switch next to Developer mode.
- Click the "Load unpacked" button and select the LeaveAKudos directory.

To use:
- From the Create Entry page in Dreamwidth, make sure you're clicked into the entry text box. 
- Type `Ctrl + Y` 
- You can add the kudos code before or after you type out your post text. It will always append to the end of whatever text is already in there.
